# RepairLens AI

RepairLens AI is an AI-powered repair decision assistant that helps users
understand device problems before choosing a repair or replacement.

## What users provide

- Device details
- A description of the issue
- An image of the damaged device

## What RepairLens AI provides

- Analysis of available inputs to identify likely problems
- Potential root causes with confidence levels
- Repair cost estimates
- Repair-versus-replacement guidance
- Safe troubleshooting suggestions

RepairLens AI is designed to make repair decisions easier, clearer, and more
informed.
